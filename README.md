# SkyCompute Frontend — Cloud & GPU Rental Client

Клієнтський вебзастосунок для хмарної платформи оренди серверів та прискорювачів **SkyCompute**. Реалізовано реєстрацію, JWT-авторизацію (`access` + `refresh` токени), захищені сторінки з перенаправленнями, рольове розмежування прав доступу (`user` / `admin`) та автоматичне оновлення `access`-токена.

---

## Адреси та порти

| Сервіс | Адреса | Порт | Призначення |
| --- | --- | --- | --- |
| **Frontend** (цей репозиторій) | `http://localhost:3000` або `http://127.0.0.1:3000` | `3000` | Клієнтський вебінтерфейс (Vite SPA) |
| **Backend** (Django REST API) | `http://127.0.0.1:8000/api/v1/` | `8000` | REST API (автентифікація, профіль, каталог) |

---

## Реалізовані сторінки та маршрути

1. **Публічний каталог (`/catalog` або `/`):**
   - Доступний усім користувачам (включно з неавторизованими).
   - Відображення списку серверів (`GET /api/v1/instances`), живий пошук, фільтрація за категорією, датацентром і вендором, сортування, пагінація та детальне модальне вікно конфігурації (`GET /api/v1/instances/{id}`).
2. **Сторінка реєстрації (`/register`):**
   - Поля: `username` (обов'язкове), `first_name` (необов'язкове), `last_name` (необов'язкове), `email` (обов'язкове), `password` (обов'язкове), `password_confirmation` (обов'язкове).
   - Повна валідація та виведення помилок окремо під кожним полем з відповіді `400 Bad Request`.
3. **Сторінка логіну (`/login`):**
   - Вхід за `username` і `password` (`POST /api/v1/auth/login`), збереження `access` та `refresh` JWT-токенів у клієнтському сховищі.
   - Містить кнопки швидкого заповнення демо-акаунтів (`developer / DevPass123!` та `admin / AdminPass123!`).
4. **Кабінет авторизованого користувача (`/workspace`):**
   - Доступний лише авторизованим користувачам.
   - Перегляд і редагування власного профілю (`GET / PATCH /api/v1/users/me`).
   - Форма створення нової конфігурації сервера в каталозі (`POST /api/v1/instances`).
   - Інтерактивний блок демонстрації автоматичного оновлення `access`-токена через `refresh`-токен (`POST /api/v1/auth/refresh`).
5. **Панель адміністрування інфраструктури (`/admin-panel`):**
   - Захищена сторінка з функціоналом для ролі `admin` (`is_staff=True`): реєстрація нових датацентрів (`POST /api/v1/datacenters`) та видалення серверів (`DELETE /api/v1/instances/{id}`).
   - Демонструє різницю між ролями `user` (отримує `403 Forbidden`) та `admin` (`201 Created` / `204 No Content`).

## Поведінка маршрутизації та токенів

* **Захист приватних сторінок:** Якщо неавторизований користувач відкриває `/workspace` або `/admin-panel`, його автоматично перенаправляє на `/login?next=<маршрут>`.
* **Повернення після логіну:** Після успішного входу користувача автоматично повертає на ту сторінку, з якої його перенаправило на логін.
* **Заборона `/login` для авторизованих:** Авторизований користувач при спробі відкрити `/login` або `/register` автоматично перенаправляється на сторінку з контентом (`/workspace`).
* **Відображення елементів у шапці:**
  * Неавторизований користувач бачить кнопку **«Увійти»** (та «Реєстрація») і не бачить кнопки «Вийти».
  * Авторизований користувач бачить своє ім'я, `@username`, бейдж ролі (`user` або `admin`) і кнопку **«Вийти»**, а кнопка «Увійти» прихована.
* **Вихід (Logout):** При натисканні «Вийти» збережені `access` та `refresh` токени видаляються з `localStorage`.
* **Автоматичний Refresh токена:** Коли термін дії `access`-токена закінчується (або сервер повертає `401 token_not_valid`), клієнт прозоро виконує запит `POST /api/v1/auth/refresh` із `refresh`-токеном, зберігає новий `access`-токен і автоматично повторює початковий запит без розлогінення користувача.

## Як запустити проєкт

### 1. Запуск бекенду (порт `8000`)

У директорії бекенд-репозиторію виконайте:

```bash
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux / macOS

python manage.py migrate
python manage.py loaddata sample_data
python manage.py runserver 127.0.0.1:8000
```

### 2. Запуск фронтенду (порт `3000`)

У кореневій директорії цього репозиторію виконайте:

```bash
npm install
npm run dev
```

Відкрийте у браузері: **[http://localhost:3000](http://localhost:3000)**
